# 1688 Cookie 同步扩展

## 安装

1. Chrome 或 Edge 打开扩展管理页，启用开发者模式。
2. 选择“加载已解压的扩展程序”，选择本目录。
3. 在当前浏览器配置中登录 1688。
4. 打开扩展弹窗，填写服务地址、Cookie 上传密钥和检测页面，保存并允许访问服务地址。
5. 点击“手动上传”，查看同步结果。

默认检测页面为用户指定的商品详情页。保存配置后，每 30 分钟自动同步。浏览器关闭或系统休眠时不保证准点执行。

## 使用

- 后台打开检测页和账号管理页，不主动抢焦点。
- 使用账号管理页顶部昵称区分账号。这是用户批准的实验方案：昵称改变会产生新账号，重名可能覆盖同名账号。
- 检测到验证信号时保留页面并通知；点击通知定位页面，手动完成验证后再次上传。
- 无法确认昵称和登录状态时不上传。
- 上传成功只恢复该昵称对应账号，然后关闭扩展创建的页面。
- 失败时显示错误，不立即自动重试；下次定时或手动触发继续检查。
- 已保留的页面会复用，不自动刷新或关闭普通用户页面。修改检测地址后，关闭原保留检测页，下次同步使用新地址。
- 多账号持续同步请使用不同浏览器配置分别安装，不在同一 Cookie 环境模拟多个账号。
