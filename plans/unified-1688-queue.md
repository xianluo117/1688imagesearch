# 图搜与 SKU 统一队列实施计划

## 已批准范围

- 图片上传、图搜商品查询、SKU 查询共用持久化队列和统一调度器。
- 全局任务执行并发默认 1，可配置；实际 1688 请求共用随机 2～4 秒启动间隔，可配置。
- 新增 SKU 异步提交、查询、取消接口；原同步 SKU 接口也入队等待，成功结果结构保持兼容。
- 限流进入全局冷却；人机验证或登录失效进入持久化暂停，人工显式恢复。
- 复用 SQLite，不引入 Redis；首版限现有单进程部署，不承诺多实例协调。

## 实施步骤与验收边界

以下完成标记表示实现、文档及最终离线回归已完成，不表示生产部署已验收。

- [x] 1. **统一存储和迁移**：增加统一调度记录，事务化入队和领取，持久化递增序号排序。保留旧图搜任务ID、结果、依赖及取消标记；幂等迁移，已请求取消的不重做。运维须停旧消费者后单进程启动，禁止新旧共跑。
- [x] 2. **统一容量和执行**：按序领取依赖已满足的任务，不保证并发时完成顺序。三类排队加执行总容量默认100，独立工作池不再各持额度。外部图片下载不消耗1688许可，但属于上传执行阶段。
- [x] 3. **请求级限速**：MTOP和详情客户端共用请求控制器；首次请求、轮询、网络重试、令牌刷新和重定向均需许可，签名在等待后生成；既有退避与共享间隔同时满足，不叠加旧SKU启动限速。
- [x] 4. **全局保护状态**：正常、冷却、暂停及原因持久化。限流默认冷却60秒，遵守更长的可信上游指示，再次限流可延长；验证或登录异常优先暂停。失败任务保留原因，未开始任务排队，每次许可前检查状态；Cookie更新和重启不恢复，须人工显式恢复。
- [x] 5. **API兼容与新增接口**：图搜创建、查询、取消及依赖校验保留；SKU异步提交、查询、取消返回第二版结果。两版同步入口入队，保留各版本成功结构及HTTP映射；等待超时504附任务编号和查询位置，后台继续，等待者断开不取消。全局可选幂等键持久化去重，同键不同类型或参数409冲突，不按商品链接永久缓存。
- [x] 6. **状态契约**：保留五类任务状态及独立业务结果，附全局状态原因。成功类业务状态且有效SKU非空才映射成功，其他映射失败并保留结果。运行取消先记请求，底层结束后释放，迟到结果不覆盖终态。
- [x] 7. **超时与生命周期**：区分排队、同步HTTP等待、执行预算及单次网络超时。仅实际在请求入口等待保护解除的时间扣除，普通间隔和在途操作仍计入；恢复先检查取消和预算。预算耗尽不发新请求，不早释放在途名额。正常关闭停止接纳领取、保留排队并等待实际操作；异常重启至少一次执行，允许落库前已发送请求重复。
- [x] 8. **配置及可观测性**：全局并发、请求间隔、冷却配置校验；全局配置唯一权威，旧配置弃用、不叠加、不改变默认并发1。状态统计与人工恢复受搜索密钥鉴权。清理终态任务、业务结果和关联幂等记录，未结束及仍被依赖任务保留。
- [x] 9. **子任务离线测试**：覆盖混合顺序、容量、全局并发与共同限速、轮询重试重定向及签名时序、暂停冷却恢复和持久化、迁移依赖、取消超时不早释放、迟到结果、同步兼容、异步轮询、幂等清理及配置回归。使用模拟上游，不真实访问1688；记录见下节。
- [x] 10. **文档与配置模板交付**：更新模板、部署升级、接口和状态说明，集中说明单进程、至少一次边界及调速不能保证避免验证码；记录离线结果来源和未验证事项。不部署、重启、提交或在线查询。
